# 🗂 Командная библиотека промптов (Prompt Library)

Добро пожаловать в централизованное хранилище промптов команды.
Здесь мы храним, версионируем и тестируем наши лучшие шаблоны.

## Правила работы (Governance):

1. Каждый промпт имеет **Владельца** (Owner).
2. Любые изменения вносятся через **Pull Request (PR)** и проходят ревью.
3. Каждый промпт сопровождается **тест-кейсами**.
4. Промпты хранятся в формате Markdown с метаданными (Prompt Card).
