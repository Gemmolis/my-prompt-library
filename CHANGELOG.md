# Changelog

Все заметные изменения в промптах библиотеки документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [v1.0.0] - 2026-11-15

### Added (Добавлено)

- Первичная версия промпта `Event Landing Generator`.
- Создана карточка промпта (Prompt Card) с метаданными (владелец, теги, модель).
- Разработаны 3 тест-кейса для проверки качества генерации кода и дизайна.
- Внедрены переменные для адаптации под разные мероприятия: `{{event_type}}`, `{{target_audience}}`, `{{brand_colors}}` и др.
- Добавлен чек-лист самопроверки для модели (Reflective) в конце промпта.

### Security (Безопасность)

- Добавлены жесткие ограничения на использование сторонних JS-библиотек (во избежание уязвимостей и падения производительности Lighthouse).
