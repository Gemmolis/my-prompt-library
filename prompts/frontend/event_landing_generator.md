## 2. ТЕХНИЧЕСКИЙ СТЕК (ЖЁСТКО)

- Один файл index.html: HTML + CSS + Vanilla JS внутри.
- Шрифты: только Google Fonts через <link> (не более двух семейств). По умолчанию: Manrope для заголовков, Inter для текста.
- Запрещено: jQuery, GSAP, Three.js, Tailwind, Bootstrap, препроцессоры, сборщики.
- Разрешено: CSS-переменные, backdrop-filter, clip-path, Web Animations API, IntersectionObserver, CSS @keyframes, matchMedia.
- Изображения: не более одной фотографии на первом экране (через background-image). Если фото нет — CSS-градиенты или SVG. Никаких <img>.
- SVG — только inline.

## 3. ВИЗУАЛЬНЫЙ СТИЛЬ И СТРУКТУРА

- Все цвета вынеси в :root. Если в брифе нет цветов, используй нейтральную палитру (по умолчанию: bg #17191d, text #f5f2ec, accent #c5a66a).
- Не навязывай всем событиям темную палитру или золото, если это не подходит {{event_vibe}}.
- **Hero:** 100svh (с фоллбэком 100vh). Kicker, крупный заголовок, описание, бейдж с датой, кнопка CTA. Внизу анимированная стрелка.
- **Программа:** Выведи ровно те пункты, что в брифе. Сетка auto-fit, minmax(250px, 1fr). Staggered-анимация при скролле. Используй <time>.
- **Место/Формат:** Для офлайн — <address> и ссылка на карту. Для онлайн — ссылка на платформу. Для гибрида — оба варианта.
- **CTA-секция:** Кнопка pill-формы (min-height 62px). Не имитируй успешную отправку, если нет реального endpoint. Конфетти разрешено только для подходящих по настроению событий (не для деловых/памятных).
- **Footer:** Название, организатор, год.

## 4. ИНТЕРАКТИВ И ДОСТУПНОСТЬ

- Scroll Reveal: IntersectionObserver (threshold 0.12). Класс .is-visible. Если JS отключен, контент должен быть виден.
- Обязательно: prefers-reduced-motion (отключить все анимации, оставить статичный контент).
- Доступность (WCAG AA): семантические теги, aria-label для иконок, aria-live="polite" для сообщений, skip-link, :focus-visible.
- SEO: <meta name="description">, og:title, og:image, theme-color.
- Мобильный фокус: 380px / 700px / 860px. Учесть env(safe-area-inset-\*).
