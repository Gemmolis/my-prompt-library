# 🧪 Test Cases: Event Landing Generator v1.0.0

Тестирование проводится перед каждым релизом (Minor или Major) для предотвращения деградации качества генерации.
Для проверки скопируйте промпт из `event_landing_generator.md`, подставьте данные из тест-кейса и запустите в LLM.

---

### Тест-кейс 1: "Сдержанное мероприятие" (Проверка контекста и отсутствия клише)

- **Входные данные:**
  - `event_type`: Деловая конференция
  - `event_vibe`: Строгий, технологичный
  - `hero_image_url`: null (нет фото)
- **Действие:** Отправка промпта.
- **Ожидаемый результат (Pass):**
  1. В CSS не используются "свадебные" атрибуты (золотые акценты `#c5a66a`, засечки, конфетти).
  2. Вместо фотографии используется выразительный CSS-градиент или SVG-графика.
  3. Палитра соответствует деловому стилю (например, синие/серые тона).

### Тест-кейс 2: "Доступность и Reduced Motion" (Проверка кода)

- **Входные данные:** Любой бриф (например, "Музыкальный фестиваль").
- **Действие:** Поиск по сгенерированному коду.
- **Ожидаемый результат (Pass):**
  1. Присутствует медиазапрос `@media (prefers-reduced-motion: reduce)`.
  2. Внутри него отключаются `animation`, `transition` и `scroll-behavior`.
  3. У интерактивных элементов (кнопки, ссылки) есть стили `:focus-visible`.
  4. Присутствует атрибут `aria-live="polite"` для уведомлений о действиях.

### Тест-кейс 3: "Чистота стека и формата" (Проверка ограничений)

- **Входные данные:** Бриф с длинным описанием и 5 пунктами программы.
- **Действие:** Генерация.
- **Ожидаемый результат (Pass):**
  1. Вывод начинается с ` ```html ` и заканчивается ` ``` `. Нет вводных слов вроде "Вот ваш код:".
  2. В коде нет тегов `<img>`, нет подключений `jQuery`, `Tailwind`, `Bootstrap`.
  3. Все цвета находятся исключительно в псевдоклассе `:root`.
  4. Программа выведена ровно из 5 пунктов (модель не выдумала лишние).
